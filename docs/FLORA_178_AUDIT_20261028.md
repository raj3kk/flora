# Flora 178-feature audit — video vs app (2026-10-28, v2.13 tak)

Source: video se nikle 178 items (V5 124 + Maya Home 22 + Wake Word 32),
mapping file REBUILD_SPEC_178.md me hai. Neeche module-wise sach hai —
koi item "hai" tabhi likha hai jab uska code app me hai aur CI PASS hai.
"NAHI" matlab code zero hai, koi daava nahi. "AADHA" matlab kuch hissa
hai, kuch baaki hai.

## Setup / Onboarding — HAI (v2.13 wizard)
- 3-step wizard: Welcome, Permissions (per-item tap, Sab-allow se
  system dialogs ek-ek karke, App-settings fallback, mic zaroori),
  Background (battery, auto-start, accessibility settings route).
- Gemini key setup, licence activation (UPI + UTR + admin approve),
  free-mode banner, battery guidance.
- NAHI: Default assistant role (is ke liye poora VoiceInteractionService
  chahiye — alag bada kaam hai, is push me nahi).

## Core chat / Home — HAI (aadha hissa baaki)
- Chat (voice + text), Scan camera, Memories (edit/delete, on-device),
  background wakeup v0, boot start (v2.12), dropdown menu se full-screen
  pages (v2.12).
- AADHA: auto memory (manual save hai, auto-save nahi).
- NAHI: Incognito mode.

## Persona / Voice / Language — AADHA
- HAI: personas tone-only (Flora/Saathi/Guru), system TTS (hi-IN → EN).
- NAHI: naam/gender save, STT choice (Deepgram), TTS choice
  (ElevenLabs), languages list, per-persona voices.
- AADHA: music (YouTube search kholta hai, music-app control nahi).

## Tools — AADHA
- HAI: Documents, currency, dictionary, search (DuckDuckGo/Tavily),
  stock price (Yahoo Finance), website starter (text-only, imaandaari
  se likha hai ki file save nahi hoti).
- NAHI: Marketing tools, Hosting, Whiteboard, drawer menu UI, builtin
  task list, home widgets, image generation (Pollinations).
- AADHA: Study (search summary hai, poora whiteboard nahi).

## Communication — AADHA (v2.13 me naam se call/SMS aaya)
- HAI (v2.13): "call <naam>" / "sms <naam> <message>" — Contacts se
  number dhoondh kar, phir ek confirmation ke baad hi call/SMS.
- NAHI: WhatsApp auto-reply/alert/group report, email read/reply,
  post history, social auto-posting (ye hamesha confirmation-gated hi
  rahega — silent posting kabhi nahi).

## Appearance — AADHA
- HAI: themes (light/dark/warm), FloraOrb canvas.
- NAHI: 3D, live wallpaper, floating charm, edge glow (Pro text me
  "abhi available nahi" imaandaari se likha hai).

## Calls / Driving / Events — AADHA
- HAI: call announce toggle, driving mode, event triggers
  (charger/battery), dialer role + InCallService greeting.
- AADHA: call uthake baat — speaker se greeting bajti hai, doosri
  taraf saaf sunai de iski guarantee Android API se nahi milti
  (phone test se hi pakka hoga).

## Agentic (skills / sub-agents / orchestrator) — NAHI
- HAI: multi-key rotation (Gemini 1 → 2 → Groq 1 → 2) + brain-proxy
  step 1 (server lane, keys unset par 503).
- NAHI: skills install, sub-agents, orchestrator router, thinking
  toggle, provider list refresh.
- 700+ tools ka daava EXCLUDED hai (unverified claim) — Flora ka
  apna metric tool-by-tool badhega, daava nahi.

## Security — AADHA
- HAI: PIN (KeyStore, default OFF), Guardian mode, Face Lock (PIN
  gate + face presence), SOS (max 3), licence device rule.
- AADHA: Voice Guardian — voice-match frontend validation PASS hai
  (asli encoder par test), par Kotlin port + enrol/match UI abhi
  baaki hai.
- NAHI: Touch Guard, gallery face scan, morning welcome, watchman,
  failed-attempts log.

## Monetization / Licence — HAI
- Free 10 min/day, Pro ₹199/month, UPI + UTR + admin approve,
  1 phone / 15 din me max 1 change (server rule live hai).

## Maya Home hardware (22 items) — NAHI (alag track)
- Box control UI, family share, bill prediction, relay control —
  ye hardware track hai, safety gates (trained electrician, MCB OFF,
  5A/channel) ke saath alag se banega. App me iska koi UI abhi nahi
  hai, aur hone ka daava bhi nahi hai.

## Wake Word (32 items) — v0 HAI, neural NAHI
- HAI (v2.4): "Hey Flora" template v0, 3-sample enrolment,
  foreground service + notification, 10s cooldown, koi unlock/action
  nahi karta.
- NAHI: neural model (PyTorch → ONNX → TFLite) — 6 clips se CNN
  overfit hota, aur VM par framework nahi tha; energy gate,
  minimum-4-frames guard, wake+command ek saath bhi nahi.
- Creator ke accuracy daave (89%+) EXCLUDED hain — Flora ka apna
  false-accept/false-reject metric phone test se banega.

## Kabhi nahi banega (excluded, user order se bhi nahi badlega
## — sirf 18+/romantic wala user ke saaf shabd se dobara khul sakta hai)
Romantic/18+ persona (default kabhi nahi), hard God-Mode lock, silent
screen viewing/recording, silent posting, silent call recording,
password store, creator code/UI/assets/character/trademark copy,
purani keys/backend data/signing key reuse, payment auto-confirm,
screen-to-server (sirf user-chuni photo ka opt-in vision Q&A alag hai).

## Is audit ka matlab
Video ke 178 me se core product (app + backend + DB + website) ka
zyada hissa code me hai, par "sab kuch" abhi nahi hai — upar NAHI
wali list hi baaki kaam hai. Agle phases isi list se ek-ek karke
honge, har item Verify → Test → Audit ke saath. Koi NAHI item ko
"hai" likh kar fake complete nahi kiya jayega.
