# Personas (v1.8) — phone test entry (per-item audit gate)

Personas audit ke teeno hisse me se (c) yahan taiyaar hai; (a) code
audit done hai, (b) CI result push ke baad aayega. Ye entry test plan
me merge hogi jab personas audit PASS ho jayega.

## Phone par check karne wale steps
1. Settings kholo — "Persona" section me 3 buttons dikhne chahiye
   (Flora, Saathi, Guru), Flora selected hona chahiye (default).
2. Saathi chuno, phir Chat me koi sawaal bhejo — jawab dostana aur
   chhota aana chahiye (Flora default se alag tone).
3. Guru chuno, phir wahi sawaal bhejo — jawab step-by-step aur
   to-the-point aana chahiye.
4. Flora wapas chuno — jawab phir normal friendly + professional
   aana chahiye.
5. App band karke dobara kholo — chuna hua persona yaad rehna chahiye.
6. Persona sirf tone badalta hai — sawaal ka matlab ya jawab ka sach
   nahi badalna chahiye; koi 18+/romantic tone kabhi nahi aana chahiye.
