# Themes + Orb — design (v1.9, one-by-one: personas ke baad)

## Kya banega (Flora ke APNE, creator ke nahi)
- Themes: 3 color themes (Default light, Dark, Warm) — prefs THEME key,
  Material3 colorScheme se lagu. Koi image/asset copy nahi, sirf colors.
- Orb: Chat screen par ek gol animation — jab Flora bol rahi ho to
  pulse, jab sun rahi ho to halka glow, jab idle ho to static. Sirf
  Compose Canvas se bana hua, koi creator ka orb/3D asset nahi.
- 3D character/live wallpaper: alag, bada step — is item me NAHI.
  Wo personas/themes ke baad, apni design ke saath aayega.

## Audit points
- Theme change par koi text unreadable nahi hona chahiye (contrast).
- Orb animation battery par bhaari nahi honi chahiye (simple Canvas,
  koi video/GL nahi).
- Default theme wahi rahega jab tak user khud na badle.
