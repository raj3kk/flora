# Themes + Orb (v1.9) — phone test entry (per-item audit gate)

Themes audit ke teeno hisse me se (c) yahan taiyaar hai; (a) code
audit done hai, (b) CI result push ke baad aayega. Ye entry test plan
me merge hogi jab themes audit PASS ho jayega.

## Phone par check karne wale steps
1. Settings kholo — "Theme" section me 3 buttons (Light, Dark, Warm),
   Light selected hona chahiye (default).
2. Dark chuno — poora app dark rang me dikhna chahiye, koi text
   unreadable nahi hona chahiye.
3. Warm chuno — app garam (brown/cream) rang me dikhna chahiye.
4. Light wapas chuno — normal rang wapas aana chahiye.
5. App band karke dobara kholo — chuna hua theme yaad rehna chahiye.
6. Chat kholo — upar ek gol orb dikhna chahiye; jab Flora jawab
   de rahi ho (busy) to orb halka pulse karna chahiye, warna static.
7. Orb ke pulse se battery par koi bada asar nahi hona chahiye
   (sirf busy waqt pulse hota hai, idle par static).
