# Study / Coding / Market tools (v2.0) — phone test entry (per-item audit gate)

Tools audit ke teeno hisse me se (c) yahan taiyaar hai; (a) code
audit done hai, (b) CI result push ke baad aayega. Ye entry test plan
me merge hogi jab tools audit PASS ho jayega.

## Phone par check karne wale steps
1. Tools kholo — neeche 3 naye sections dikhne chahiye: Study,
   Website starter, Market.
2. Study me koi topic likh kar "Study karo" dabao — 5 tak points +
   "Source: DuckDuckGo" dikhna chahiye; andaza jawab nahi.
3. Website starter me idea likh kar "Starter banao" dabao — pages
   (Home, About, Services, Contact) + Home ka HTML skeleton dikhna
   chahiye; "file save nahi hui" note bhi.
4. Market me RELIANCE.NS ya AAPL likh kar "Price dekho" dabao —
   price + currency + change% + "live price ki pushti exchange/app
   se karo" note dikhna chahiye.
5. Galat symbol likho — imaandari se "symbol nahi mila" jaisa note
   aana chahiye, andaza price nahi.
6. Bina network ke koi tool chalao — "network ki dikkat" jaisa
   imaandari wala note aana chahiye, crash nahi.
