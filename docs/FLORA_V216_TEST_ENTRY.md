# Flora v2.16 test entry (phone par check karne ke liye)

Version: 2.16.0-rebuild, versionCode 38. CI PASS ke baad hi "done" mana jayega.

## 1. Image via ChatGPT (user order — pehle wala tareeka badal gaya)
- Pehle: Permissions screen me Accessibility ON hona chahiye (nahi to
  Flora khud Accessibility settings khol degi aur bolegi).
- "image banao ek sher" bolo.
- Flora ko: ChatGPT app kholni chahiye → prompt box me "ek sher ki
  image banao" bharna chahiye → Send dabana chahiye → bol kar
  batana chahiye ki image ChatGPT me ban rahi hai.
- Image ChatGPT app me dikhni chahiye (Flora image ko Gallery me
  nahi layegi — wo ChatGPT ke andar banegi).
- Agar ChatGPT installed nahi hai: Flora ko Play Store se install
  karna chahiye, phir wahi flow chalana chahiye.
- Agar ChatGPT ka prompt box/Send nahi mila: Flora ko saaf batana
  chahiye kya nahi mila, aur bata kar Gallery wale tareeke se
  image banana chahiye (chhupke nahi).
- ChatGPT me login/subscription manga to wo user khud karega —
  Flora login nahi karegi.

## 2. App install via Play Store
- "WhatsApp install karo" bolo (ya koi jaani app: Instagram,
  Telegram, Spotify, YouTube, Chrome, Gmail, Maps).
- Flora ko: Play Store ka us app ka page kholna chahiye → Install
  dabana chahiye (Accessibility ON ho to) → install poora hote hi
  app kholni chahiye + bol kar batana chahiye.
- Accessibility OFF ho to: Flora Play Store kholegi, tum Install
  dabao, install hote hi Flora khud app khol degi.
- Jo app jaani list me nahi hai (jaise koi chhota app): Flora
  Play Store me search kholegi, tum jo chaho us par Install dabao.
- Paid app ho to: payment ka step tumhe khud Play Store me
  confirm karna hoga — Flora payment confirm nahi karegi.

## 3. Background se bhi
- App back karke (background mic ON) "image banao ek billi" bolo —
  Flora ko app aage la kar wahi ChatGPT flow chalana chahiye.

## Phone par FAIL ho to
- Kaunsa step ruka, screen par kya dikha, Flora ne kya bola —
  ye teeno batao, tabhi root fix hoga.
