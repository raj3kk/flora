Licences (keys)

Admin se licence issue karo — ek submit = ek licence. Nayi licence aate hi user ki pehli active licence 'superseded' ho jati hai (ek user ki ek waqt par sirf ek active licence). Ek licence ek waqt par sirf ek device par chalti hai (15-day transfer rule; admin Rebind wait ka bypass hai). Key list me hamesha masked dikhegi (sirf last 4) — poori key dekhne/copy karne ke liye Show dabao (reveal audit me darj hoga). Create ke baad full key EK BAAR dikhegi — uske baad sirf masked. Keyless rows (payment-approved, bina key) waise hi chalti hain.
