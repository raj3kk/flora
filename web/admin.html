Flora Admin

Login ke baad yahan tumhara email aur admin status dikhega.

Admin nahi ho. Isliye approve/reject nahi chal raha — server tumhe 403 dega. Admin banne ke liye: (1) app me Settings → “Website account link” me isi email se link karo (isse tumhari users row banegi), (2) phir admin flag lagaya jayega, (3) uske baad ye panel poora chalega.

Login

Abhi login nahi hua hai.

Payments / UTR approvals

Saare users ke payments (server function se — RLS list yahan kaam nahi karti). Amount + UTR + note match karke approve (licence active) ya reject (reason zaroori) karo. Har approval admin_audit me darj hoga. Approve/reject sirf admin-approve function se hota hai.

Login ke baad list yahan aayegi.

Users & Licences

Har user: email, device, admin badge, licence plan/status/expiry, push token (haan/naa), usage total. Email auth se aati hai; token value kabhi nahi aati.

Login ke baad list yahan aayegi.

App connection

Kaunsa user app se juda hai: device + push token presence + token ki aakhri update. "Last active" nahi likha hai — sirf token-updated time hai, kyunki token update hi connection ka saboot hai.

Login ke baad list yahan aayegi.

Usage

Har user ka total talk seconds + tool calls (mili hui usage rows ka jod). Free limit 600 talk sec/day hai — neeche wala jod all-time hai, roz ka limit isse alag check hota hai.

Login ke baad list yahan aayegi.

Push bhejo

Sirf fixed templates chalte hain (send-push function manmana title/body reject karta hai). "Sabhi users" par sirf un users ko bheja jayega jinke paas push token hai — bina token wale skip honge aur count me dikhenge.

Keys (provider keys)

Status sirf present/missing batata hai — key ki VALUE kabhi yahan nahi dikhegi, kabhi log nahi hogi. Dashboard secrets (env) zyada secure hain aur hamesha pehle jeetenge; yahan set ki gayi key sirf fallback hai (jab dashboard secret na ho). Delete karne se pehle confirm poochha jayega.

Login ke baad status yahan aayega.

UPI (website pay page)

Ye UPI ID website ke pay page par dikhega, taaki customer ko app ke Pro screen par na dekhna pade. App apna local UPI VPA tab tak dikhata rahega jab tak app build server UPI na padhne lage (wo follow-up kaam hai).

Audit log

Append-only: kaun admin, kya action, kis user par. Admin hi dekh sakta hai (RLS).

Login ke baad log yahan aayega.

Plans

Sirf view. Price change owner-gated hai — admin propose karega, owner confirm karega. Is panel se price edit nahi hota.

Free: 600 talk sec/day, basic tools. Pro: ₹199/mahina, unlimited talk, sab tools, FCM push. (Live wallpaper aur conversation mode abhi available nahi hain — baad me aayenge.)

Secrets status

Do tareeke hain: (1) Supabase dashboard secrets (env) — zyada secure, hamesha pehle jeetenge; inki values/status is panel par kabhi nahi aayengi, sirf Supabase dashboard (owner-only) se dekhi ja sakti hain. (2) Panel DB keys (provider_keys table) — service-role-only, at-rest encrypted nahi, sirf fallback; inka status upar Keys section me booleans me dikhta hai. Key ki VALUE kabhi panel par nahi dikhegi.
